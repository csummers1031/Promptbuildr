- `code`/`ux` · **Fixed the share flow (the viral loop).** The share button after generating a prompt was sharing a `/?remix=1&task=...` link that only carried the FORM INPUTS, so a recipient (person or AI) saw a blank prefilled form and had to click Generate again (a wasted API call that could produce a different prompt). Now the generate API returns the promoted `slug`, and the share points at the prompt's own page `/prompts/<slug>`, where the recipient sees the full generated prompt, copy button, recommended tools, and the existing "Remix this in the builder" CTA (loop closes: view -> build your own). Falls back to the remix link only when a prompt didn't qualify for promotion (so there's no page). Added a small line under the share bar telling the user their prompt now has its own page. The shared page unfurls with the new per-prompt OG card. Ref: deploy #34 (pending). Follow-up idea noted: for "duplicate" prompts, point the share at the existing live page instead of the remix fallback.
